# Module attribution

Curated modules in this directory are derived from community blueprints (SPEC §5.4, D19: attribution is
mandatory). The original blueprint strings are cached in `sources/` as fetched from factorioprints.com's public
API. The site states no licence; the authors keep their rights. Each module was normalised to early-game tech
for Rival Engineers (machine and inserter tiers, recipes, ports); the module's `notes` list every change.
